## 背景与移动端

- 添加梯度下降、神经网络、反向传播、CNN 和 Transformer 的装饰示意图。
- 使用灰色和墨蓝色，桌面图形随滚动缓慢移动，并以曲线产生概念联系；中间阅读区域保留遮罩。
- 示例 token 持续缓慢移动，用 CSS transform 完成，不增加逐帧 JavaScript。
- 手机上只保留静态梯度下降和 CNN 示意图，继续移动五个 token；关闭其余图形动画和背景滚动监听。
- 页面隐藏时暂停动画，遵循减少动态效果的系统偏好。

## DeepSeek AI twin

- 通过已有 Supabase 项目的 `ai-twin` Edge Function 调用 DeepSeek，密钥保存在服务端 Secrets。
- 支持一般问题和多轮上下文；个人资料由服务端提供，要求模型不虚构经历和成果。
- 等待回答时阻止重复发送；失败时明确提示并恢复问题；回复按纯文本显示。
- 单条输入最多 2,000 字符，上下文最多 12,000 字符，回复最多 900 tokens。
- 使用数据库持久配额：全站每日 UTC 200 次、每 IP 哈希每 10 分钟 20 次。来源检查不等同于身份认证，全站配额提供请求总量限制。
- 无联网搜索。当前页会话只保存在内存中，问题及相关历史发送给 DeepSeek；数据库不保存对话。
- Dashboard 单文件部署版由 `scripts/build-ai-twin-dashboard.mjs` 从两个服务端源文件生成。
