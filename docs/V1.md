# 个人主页 V1（MVP）迭代记录

## 一、本次目标
- 让访客快速理解：“我是谁 / 我做过什么 / 下一步可以做什么”
- 实现一个可在本地运行、结构清楚的静态个人主页

## 二、用户 / 受众
- 潜在雇主、课程老师、同学、想认识你的同行
- 别人打开后 30 秒内能明白你是谁

## 三、页面结构
- Hero（姓名 + 一句话 + 联系方式入口）
- About（学校 / 专业 / 年级 / 方向）
- Projects（真实项目）
- Contact（邮箱 + GitHub）
